# Ubiquitous language

Accepted vocabulary for North. Open terms are deliberately excluded until the
product specification settles them.

| Term | Definition | Avoid |
| --- | --- | --- |
| Person | The person using North. Use more specific product nouns when possible. | Player, follower |
| Mascot | The three-layer compass face that registers product state without speaking or judging. Code uses `Mascot`; “North mascot” and “face” are acceptable descriptive phrases. | North by itself, character, coach |
| Reality | The onboarding picture of where a person currently stands. | Scorecard, diagnosis |
| North Star | The kind of person the person chooses to move toward. | Goal, ideal man |
| Signal | The internal name for the chosen accent family applied to Direction, primary actions, and active controls. The person-facing setting is **Profile color**. North suggests one from the North Star, but it is appearance, not a personality result. | Theme, aura, personality diagnosis |
| Direction | Degrees from the North Star, from 180 degrees to 0 degrees. The same term is used in product copy, routes, stored fields, and code. | Bearing, score, level, streak |
| Axis | One of the six dimensions North measures. Five describe conduct; Agency describes stance. | Category, pillar, trait, stat |
| Frame | The Axis for holding a position rather than dissolving to be liked. | Confidence, assertiveness |
| Desire | The Axis for pursuing what he wants rather than pre-rejecting himself. | Game, seduction |
| Connection | The Axis for initiating and sustaining bonds. | Social score, network |
| Self-command | The Axis for what owns his hours and whether he governs it. The stored prototype key remains `appetite` for local-data compatibility. | Addiction, vice, appetite, screen time |
| Craft | The Axis for what he has built, in capability and in body. | Productivity, fitness |
| Agency | The Axis for whether he believes he is the one choosing. Covers control, earned confidence, risk, and how clearly he can picture his future self. | Mindset, motivation, willpower |
| Contract | The signed agreement made at the end of onboarding, which replaces notifications. | Terms, pledge, onboarding |
| The Code | An optional authored agreement available from You. It is never required during onboarding and never pushed. | Rules, creed |
| Action | One system-proposed direction that the person interprets, names, and commits to. | Task, challenge, mission |
| Named Action | The person's concrete interpretation of an Action. | Proof, assignment |
| Open Action | The single Action currently in progress until closed or let go. | Daily task, today's action |
| Deadline | The one-to-seven-day commitment chosen for an Open Action. | Due date set by North |
| Closeout | The honor-system act of completing an Open Action. | Verification, submission |
| Note | An optional reflection attached to an Action. | Journal entry, evidence |
| Swap | One of three monthly choices to replace an unsuitable proposed Action. | Skip, reroll |
| Lesson | A short authored text attached to an Action. | AI advice, content card |
| Recalibration | A partial return to Reality after a long absence. | Penalty, reset |
| Hold North | The 30-day period after reaching a Direction of 0 degrees. | Final streak |
| Exit | The designed point at which North is no longer needed. | Churn, cancellation |

Relationships:

- Onboarding establishes a Reality, a North Star, an initial Direction, and a
  signed Contract.
- After the Contract, North previews the first Action. Account creation and a
  one-time Profile color choice then save that authored direction; neither
  interrupts the assessment.
- A Reality is measured across the six Axes. A North Star is chosen, never
  diagnosed; North does not label the kind of man a person currently is.
- At most one Open Action exists at a time.
- An Action becomes open only after the person names it and chooses a Deadline.
- A Closeout may include a Note, but neither requires proof.
- A successful Closeout may move the Direction; a missed Deadline never moves it
  backward.
- Reaching 0 degrees begins Hold North. Completing Hold North leads to Exit.
